# MMOM-project — Neural Network Potential for Silicon

**Course:** Molecular Modeling of Materials (MMOM)
**Authors:** Francesco Grassi (10841139) and Giorgio Venezia (1080030)

Behler–Parrinello Neural Network Potential for 64-atom bulk Silicon (Stillinger-Weber ground truth → symmetry functions → PyTorch training → autograd forces → Velocity Verlet MD → RDF/VDOS/Müller-Plathe validation).

## Where to look

- **Final, graded deliverable → [`GrassiVenezia_Neural_Network_Potential/`](GrassiVenezia_Neural_Network_Potential/)**
  Self-contained: `GrassiVenezia_NNP.ipynb` + `README.md` + `requirements.txt` + `assets/` + `lammps/si.lmp` + best `models/` checkpoint + `networks/` TensorBoard logs.
  Start with its [README](GrassiVenezia_Neural_Network_Potential/README.md) for results, structure, and reproduction instructions.

## Best result (see final README for details)

- Test: RMSE **0.548 eV** total (**8.56 meV/atom**), R² **0.9992**
- Forces: RMSE **≈0.86 eV/Å** vs SW
- Best checkpoint: `GrassiVenezia_Neural_Network_Potential/models/experiment_hl2_hs64_dr0p0_bs128_lr0p0001_ep1500_pt75_l20p0_0719-1424_model.pt`
