The launch of the LAMMPS code is not integrated inside the Jupiter Notebook, but all the produced files are already present in the directory lammps/
In order to launch the LAMMPS code, you need to run inside the lammps/ directory the following command:

lmp -in .\si.lmp

As the dataset with the symmetry functions is too big, we do not include it in this directory, however it should be automatically generated by our Jupiter Notebook
